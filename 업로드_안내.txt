GitHub 업로드 방법

1. ZIP을 "모두 압축 풀기"로 풉니다.
2. GitHub 저장소에서 Add file → Upload files를 누릅니다.
3. 압축을 푼 폴더의 안쪽 파일들과 "교재" 폴더를 함께 끌어다 놓습니다.
   ZIP 파일이나 바깥쪽 "학습노하우_GitHub업로드용" 폴더 자체를 올리지 마세요.
4. index.html이 기존 파일을 덮어쓰도록 main 브랜치에 저장합니다.

저장소의 맨 위에 README.md와 index.html, 활동지 파일들이 보이고
같은 위치에 "교재" 폴더가 보이면 맞습니다.

교재 폴더에는 강의계획서 원문과 디지털 노마드 1장 열람용 PDF가 있습니다.
공개 저장소에 올린 파일은 사이트 방문자 외의 사람도 접근할 수 있습니다.

HTML의 제목·주차별 계획·자료·활동지 문항은 유지했습니다.
내 컴퓨터 주소를 웹용 상대경로로 바꾸고, 자료집으로 돌아오는 링크를 index.html로 맞췄습니다.
교재 1장 PDF는 업로드 가능한 크기로 줄인 17쪽 열람용 사본이며 원본은 변경하지 않았습니다.

이후 수정한 HTML을 저장하면 index.html이 내려받아집니다.
그 파일을 같은 저장소의 index.html에 덮어 올리면 공유 주소는 유지됩니다.
